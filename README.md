# PDF Library

Android app source for an offline PDF reader with a persistent personal library.

## Features
- Opens local PDFs with Android's document picker
- Saves reading position separately for every PDF
- Reopens the last PDF on the last page you were reading
- Library view with cover thumbnails based on the first page of each PDF
- Load new PDFs into the library
- Previous / Next buttons at the bottom
- Swipe to change pages
- Pinch to zoom, double tap to zoom, drag while zoomed
- Dark grey and blue UI
- Blue open-book launcher icon
- No internet permission

## Build
Open the `PDFBookmarkReader` folder in Android Studio and build normally,
or use a GitHub Actions workflow that builds the extracted project.
